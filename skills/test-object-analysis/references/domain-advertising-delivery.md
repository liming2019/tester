# 广告投放领域对象扫描参考

当需求属于广告账户、投放平台、磁力金牛、账户资金、投放报表、广告计划、广告单元、创意审核等场景时，读取本参考。

本参考用于补充领域对象扫描，不替代 `SKILL.md` 中的通用证据等级、对象分析规则和下游输出格式。

## 优先扫描对象

- 账户对象：账户类型、账户状态、开户资质、冻结/解冻、主子账号关系。
- 资金对象：余额、充值、退款、授信、消耗、发票、合同、流水一致性。
- 广告对象：计划、单元、创意、预算、出价、定向、审核状态、投放状态。
- 权限对象：主账号、子账号、代理商、运营、财务、只读角色、跨账户访问。
- 报表对象：消耗、转化、指标口径、数据延迟、维度切换、导出一致性。

## 常见高风险场景

- 账户冻结、资质不全、余额不足、授信额度不足时，创建、启停、审核和投放动作是否被正确限制。
- 主账号、子账号、代理商、运营、财务、只读角色之间的入口权限、按钮权限和接口鉴权是否一致。
- 广告计划、广告单元、创意之间的状态联动是否正确，例如创意审核拒绝后计划或单元的可投状态。
- 预算、出价、消耗、余额、发票、合同、流水之间的数据口径是否一致。
- 报表指标是否受数据延迟、维度切换、时间范围、导出范围和历史数据兼容影响。

## 输出要求

- 只输出材料支持或项目规则已验证的对象和场景。
- 不要为了套用本参考而补不存在的广告对象、资金对象或报表对象。
- 对缺少证据的投放规则、资金口径、审核状态和报表指标，写入待确认项。
