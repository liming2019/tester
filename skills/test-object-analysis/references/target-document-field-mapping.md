# 目标单据字段映射参考

当需求涉及源系统、OA、中间层、第三方单据、目标业务单据、字段映射表、拆单、合单、分组、汇总或单据回写时，读取本参考。

本参考用于防止只验证“单据创建成功”，而漏掉目标单据字段映射、主数据编码转换和明细归属。

## 必须拆出的对象

当需求涉及“源系统 / OA / 中间层创建第三方或目标业务单据”时，必须单独拆出目标单据字段映射对象，不能只把“创建成功”作为主链路覆盖。

至少识别以下内容：

- 目标单据单头字段：申请人、公司、部门、日期、接收人、状态、备注等材料明确出现的字段。
- 目标单据明细字段：商品、资产、数量、金额、编码、序号、分类等材料明确出现的字段。
- 源字段到目标字段的映射关系、映射配置、主数据编码转换和生效口径。
- 拆单、合单、分组、汇总后，每张目标单据的字段归属是否仍对应正确源明细。
- 创建请求字段、回查字段、页面展示字段和本地回写字段之间的一致性。
- 映射缺失、禁用、无权限、多义、缓存过期或主数据漂移时的阻断和异常回写。

## 待确认规则

如果字段来源或映射确认表缺失，不得省略该测试对象；必须写入待确认项，并在下游输入中保留“按映射确认表逐项核对 / 映射表缺失时阻塞”的测试对象。

## 输出要求

- 区分单头字段、明细字段、主数据映射、拆合单规则和回写字段。
- 对每个映射类测试对象标明来源证据，避免把经验字段当成需求事实。
- 若只能确认创建请求，不能确认目标回查或页面展示，必须标为覆盖缺口或待确认项。
