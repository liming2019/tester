## 字段写法要求

- `测试标题` 必须可单独阅读并概括主验证目标，例如“执行数为 0 时阻断保存和提交”；不要只写模块名、功能点名或“校验正确”。
- `操作步骤` 使用有序步骤，避免把多个独立流程塞在同一条用例中。
- `预期结果` 必须对应每个关键步骤，能通过页面、接口、数据库、日志或报表验证。
- `来源依据` 写材料来源，例如“PRD-字段规则”“原型-新增弹窗”“对象分析-权限边界”“测试补充-边界值”。
- `是否可自动化` 使用 `是`、`否`、`部分可自动化`、`待确认`。
- `备注` 只写限制、前置缺口、数据准备方式或回归建议，不写空泛说明。
