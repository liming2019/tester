# 输入模板

当用户提供的信息不足以安全生成可执行 SQL 时，要求其尽量按以下模板补充：

```text
目标数据库类型:
目标库名:
目标表名:

目标字段元数据:
- 字段名 / 类型 / 长度或精度 / 可否为空 / 是否唯一 / 默认值

参考数据库类型:
参考库名:
参考表名:
参考字段:
参考过滤条件（WHERE 原样保留）:

字段映射关系:
- target_field_a -> reference_field_x
- target_field_b -> reference_field_y

生成条数:

非关联字段生成规则:
- 可不填
- 仅当你希望覆盖脚本基于“字段注释 / 字段名 / 字段类型”的自动生成策略时再补充
- 示例:
  - field_c: 固定值 / 前缀规则 / 枚举范围 / 时间规则
  - field_d: 唯一值规则

补充限制:
- 是否允许 INSERT INTO ... SELECT:
- 是否必须输出字面量 VALUES:
- 主键 / 唯一键 / 外键约束:
```

如果用户提供了 DDL、`DESC` 结果、表结构截图或样例数据，先从这些材料中提取约束信息，再决定是否生成最终 SQL。
