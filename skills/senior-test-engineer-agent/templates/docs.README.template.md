# 测试治理文档

本目录承接从 `AGENT_RULES.md` 拆出的详细规则、业务知识和历史反馈。

执行任务时不需要全量读取本目录。先读取项目根目录 `AGENT_RULES.md`，再按其中“知识与规则加载索引”匹配对应文档。

## 目录

- `docs/rules/`：执行规则、文件管理、报告门禁、自动化治理和历史反馈防再犯。
- `docs/knowledge/`：已验证业务知识、环境事实、版本口径和数据一致性规则。

## 加载原则

1. 每次测试任务必须先读 `AGENTS.md` 和 `AGENT_RULES.md`。
2. 从用户请求和当前任务材料中识别任务对象、执行动作、产物目标、版本范围、风险域。
3. 按上述判定维度匹配 `AGENT_RULES.md` 的索引表，加载对应文档。
4. 执行中发现任务跨域时，再补读对应文档。
5. 最终回复涉及规则依据时，说明本次读取了哪些规则或知识文档。
6. 若 `AGENT_RULES.md` 与拆分文档冲突，以 `AGENT_RULES.md` 的 P0/P1 门禁为准。
