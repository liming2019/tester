# AGENTS.md

本项目所有测试相关任务，默认使用 `$senior-test-engineer-agent` 处理。

执行任何测试任务前，必须先读取当前项目根目录的 `AGENT_RULES.md`，并将其作为项目级最高测试准则。

测试任务包括但不限于：需求分析、蓝湖/原型测试点提取、测试用例设计、功能测试、接口测试、性能测试、Playwright 自动化脚本、数据库 SQL 校验、缺陷分析、复测与测试报告输出。

## 默认执行规则

- 若用户提出测试相关需求，优先按 `$senior-test-engineer-agent` 的规则执行。
- 若当前任务命中专项 Skill 场景，必须按 `AGENT_RULES.md` 中的专项 Skill 调度规则执行。
- 若 `AGENT_RULES.md` 缺失，必须先提示创建或同步项目测试规则，再继续执行项目测试任务。
- 若用户需求不合法、不清晰、范围不明、材料不足或存在高风险操作，必须先明确指出问题、影响、需补充信息和可先执行事项。
- 执行过程中必须主动识别潜在优化点，并说明优化依据、为什么要做、预期收益、落地方式和优先级。
- 输出产物必须按 `AGENT_RULES.md` 的项目目录规范归档。
