## 报告生成器

- 生成或重建正式测试报告时必须使用公共报告生成器或已确认的报告生成链路。
- 不得手写临时 HTML 作为正式报告。
- 正式报告包纳入 `reports/final/` 或更新 `reports/current.md` 后，必须运行 `automation/validate_report_package.py`。
- 最终回复涉及报告交付时，必须说明已完成自审和剩余风险。
