# 测试点矩阵

使用本矩阵避免接口用例设计停留在“请求成功”层面。

## 正常场景

- 最小合法请求
- 全量合法请求
- 每个独立筛选或动作参数
- 合法参数组合
- 预期有数据返回
- 预期空结果返回

## 边界场景

- 字符串最小/最大长度
- 数值最小/最大值和精度
- 时间开始/结束边界是否包含
- 枚举每个合法值
- pageNo/pageSize 最小值和最大值
- 批量数量上限
- 合法筛选条件下的空列表

## 异常场景

- 缺少必填参数
- 参数类型错误
- 参数格式错误
- 非法枚举值
- 超出范围
- null、空字符串、空白字符串
- 开始值大于结束值
- 不支持的参数组合
- JSON 格式错误或 Content-Type 不匹配

## 权限与安全

- 未传 token 或 token 非法
- token 过期
- 无资源权限
- 跨租户、跨店铺、跨账户访问
- 用户角色边界
- 接口存在签名时的签名错误、nonce 重放
- 响应和日志敏感信息脱敏

## 分页、排序、筛选

- pageNo/pageSize 基础查询
- pageSize 上限
- 首页、中间页、末页
- cursor 首次读取和续读
- cursor 与 page 参数同时传
- 跨页不重复、不漏数
- 重复请求排序稳定
- 分页过程中筛选条件持续生效

## 兼容性

- 老请求体不传新增参数
- 新参数不传
- 新参数单独传
- 新参数与旧筛选条件组合
- 老客户端仍传废弃参数
- 未知额外参数处理
- 默认值行为

## 数据正确性

- 返回记录符合请求筛选条件
- 业务唯一键能映射到源数据
- 金额精度和舍入
- 时区和时间格式
- 状态和枚举映射
- 主明细数量和关系一致
- 有条件时与数据库或下游数据一致
