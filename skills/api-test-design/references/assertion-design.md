# 断言设计

断言必须证明业务行为正确，不能只证明链路可达。

## 基础断言

- HTTP 状态码
- 业务 code
- 业务 message
- 响应 Content-Type
- 必要顶层字段
- JSON 结构或字段存在性

## 契约断言

- 类型正确
- 格式正确
- 枚举值正确
- 可空性正确
- 列表结构正确
- 分页字段正确
- 错误响应结构正确

## 业务断言

- 返回记录符合请求筛选条件
- 资源属于调用方权限范围
- 状态流转正确
- 金额、数量、状态正确
- 时间范围边界符合文档定义
- 主明细关系一致

## 证据要求

可执行接口测试必须采集：

- 请求方法和 URL
- 脱敏后的请求头
- 请求 query/path/body 参数
- 脱敏后的原始响应
- 解析后的响应
- 原始响应较大或加密时记录响应哈希
- 使用数据库或下游数据对账时记录对账结果
- 断言结果和失败原因
