# 目标单据字段映射测试点提取参考

当材料中出现创建第三方单据、目标业务单据、外部系统单据、同步单据、推送单据、发放单、领用单、采购单、订单、工单、凭证、字段映射表等对接类对象时，读取本参考。

本参考用于把目标单据字段映射对象落成可评审测试点，不能只输出“创建成功 / 回查成功 / 状态回写正确”。

## 必须提取的测试点

必须根据材料明确支持的内容提取以下测试点：

- 目标单据创建成功。
- 单头字段映射正确。
- 明细字段映射正确。
- 拆单、合单或分组后的字段不串单、不串组、不串明细。
- 创建请求、目标系统回查、页面展示、本地回写字段一致。
- 映射缺失、禁用、无权限、多义或主数据失效时阻断创建或记录可定位异常原因。

## 处理边界

- 材料明确给出目标字段名时，字段名必须逐项下沉为测试点，例如 `companyCode 映射正确`、`assets[].barcode 映射正确`。
- 材料只说明存在映射但未给字段清单时，输出“按字段映射确认表逐项核对目标单据单头字段 / 明细字段”，并增加“字段映射确认表缺失时阻塞字段级验收”。
- 不得因为字段来源未确认而省略字段映射测试点；应标记为待确认或阻塞前置。
- 不得脑补材料没有出现的字段名、接口参数或数据库列。

## 输出要求

- 将单头字段、明细字段、拆合单规则、主数据映射和回写一致性拆成可评审子点。
- 对材料没有明确字段清单的场景，保留测试对象和待确认项，不伪造字段。
- 如果上游 `test-object-analysis` 已输出目标单据字段映射对象，优先消费其“下游测试点生成输入”。
